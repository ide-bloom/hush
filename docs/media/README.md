# Recording the demo GIF

`demo.gif` is currently a static placeholder generated by `build/make-demo-placeholder.py`. Replace it with a real
recording using these steps. **Never record a real secret**: use a throwaway vault and generated fake tokens.

## Setup

1. Publish a build: `./build/publish.ps1 -Runtimes win-x64`, and put `artifacts\win-x64` on `PATH` for the session.
2. Use a scratch vault and a scratch profile:

   ```powershell
   $env:HUSH_HOME = "$env:TEMP\hush-demo"
   Remove-Item -Recurse -Force $env:HUSH_HOME -ErrorAction SilentlyContinue
   ```

3. Plant a fake MCP config in a demo folder. Generate a fake GitHub-format token with a correct checksum (it does not
   work anywhere) and write it into the file, rather than pasting a real token:

   ```powershell
   $demo = "$env:TEMP\hush-demo-project"; New-Item -ItemType Directory -Force $demo | Out-Null
   Set-Location $demo
   # Build the fake token from fragments so it never appears in a script or recording verbatim.
   $body = -join ((48..57) + (65..90) + (97..122) | Get-Random -Count 30 | ForEach-Object { [char]$_ })
   Set-Content .mcp.json ('{ "mcpServers": { "github": { "command": "npx", "args": ["-y", "@modelcontextprotocol/server-github"], "env": { "GITHUB_PERSONAL_ACCESS_TOKEN": "gh' + 'p_' + $body + '000000" } } } }')
   ```

4. Windows Terminal, 120×30, font size 14, a dark theme. Clear the screen and history (`Clear-History; cls`).

## Script

Record with [ScreenToGif](https://www.screentogif.com/) (or the Windows Snipping Tool's video mode followed by a
converter) at 12 fps, cropped to the terminal:

```powershell
hush init                      # approve Windows Hello three times; the recovery key is from a throwaway vault
hush scan .  --no-defaults     # shows the planted token redacted to its first four characters
hush migrate . --no-defaults --dry-run
hush migrate . --no-defaults --yes
Get-Content .mcp.json          # the server now launches through hush run; no token in the file
hush run --secrets GITHUB_PERSONAL_ACCESS_TOKEN --mask -- cmd /c "echo token=%GITHUB_PERSONAL_ACCESS_TOKEN%"
hush lock
```

Keep it under 45 seconds. Blur the recovery-key frame anyway (it belongs to a throwaway vault, but viewers should
learn not to share one). Export as `docs/media/demo.gif`, under 5 MB, and delete the scratch folders afterwards.
